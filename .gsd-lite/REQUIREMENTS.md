# REQUIREMENTS — rec-tube

## 目的
既存の `rec.swift`（Core Audio Process Tap による macOS 音声録音 CLI）を取り込み、
URL 指定で Chrome の音声を録音する CLI として改善する。

## 確定した要求
- 主用途は `--url` モード: URL を Chrome で開き、Chrome の音声を tap してファイルに保存する
- 出発点は リポジトリ直下の `rec.swift`（313 行）。設計資料は `rec-reference.md`
- 対応 OS は macOS 26 以上。`CATapDescription.bundleIDs` と `isProcessRestoreEnabled` を使う
- 今回の改善対象は次の 4 つ:
  1. 録音データの保全（異常終了でも m4a を確定、権限なしの無音検知）
  2. 広告境界の精度向上（広告の混入と本編の欠落を減らす）
  3. 長時間録音への追従（ヘルパー再起動、出力デバイス切り替え、スリープ復帰）
  4. ビルドとプロジェクト整備（Info.plist、ビルド手順、テスト可能な構成、README）
- 他タブの音が混入する制約は README に明記する（検出や分離はしない）
- SwiftPM 構成にする。ロジックをライブラリ、CLI を実行ターゲットに分ける
- ライブ配信の URL は録音せず、理由を表示して即エラー終了する
- `--app`、引数なしのシステム全体録音、`--list` は使い方を変えずに維持し、データ保全の改善を共通で適用する
- 広告境界は広告の混入ゼロを優先する: 約 1 秒の遅延バッファで広告開始直前の音を捨て、
  広告明けは少し巻き戻して追記する。境界での本編の欠落や重複は 1 秒未満まで許容する
- Chrome ヘルパーの再起動は `isProcessRestoreEnabled` で追従する
- 出力デバイスの切り替えとスリープを検知したら、録音を止めて確定し、エラー終了する（自動復旧はしない）
- 出力名の既定: `--url` は動画タイトルをファイル名に安全な形へ整えて使う。他モードは `rec-日時.m4a`
- 既存ファイルは `-o` 指定時も含めて上書きしない。同名があれば連番を付ける
- 無音検知: 録音中は警告だけ出して続行する。終了時に全編が無音なら、許可の確認方法を表示して非ゼロ終了する
- `--url` は `<video>` 要素のあるページをベストエフォートで受け付ける。広告判定は YouTube のみ。
  ローカル検証ページもテスト専用の抜け道なしに同じ経路を通す

## 受け入れ基準
- 既存の 3 モードと `--url` が macOS 26 上でビルド・起動できる
- `rec.swift` の内容は `Sources/` に移し、ビルド手順は README に記載する
- README.md に事前設定の手順を記載する。少なくとも次を含める:
  - Xcode と `DEVELOPER_DIR` の指定、ビルドとテストの実行方法
  - Chrome の「表示 > 開発/管理 > Apple Events からの JavaScript を許可」
  - Chrome のオートメーション許可（ターミナル → Google Chrome）
  - システム音声録音の許可と、許可の付与先（ターミナル、tmux 経由の場合を含む）
  - 許可がないときの症状（無音、JS 実行エラー）と確認方法
- ライブ配信、URL 不正、タブ閉鎖、Chrome の JS 許可なしで、原因が分かるメッセージを出して非ゼロ終了する
- SIGINT / SIGTERM / 途中エラーのいずれでも、録音済みの m4a が再生できる状態で残る
- 堅牢性: どの入力・出力状態でもトレースバックを出さず、録音済みのデータを失わない
- `swift test` が成功する（`DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer`）
- verify がループ内で実機録音を行い、次の 2 つを確認する:
  - ローカル検証ページ: 既知の音と広告役の切り替えを再生し、広告混入がなく、境界の欠落と重複が 1 秒未満
  - 短い YouTube 動画: 実環境で開始から保存まで完了する

## 現状の既知の問題（rec.swift を読んで確認）
- `osa()` 内の `exit(1)` と SIGTERM で、m4a が確定されず壊れる可能性がある
- `chromeOpen` のエスケープが `"` のみで、バックスラッシュなどを含む URL で AppleScript が壊れる
- 0.3 秒ごとに osascript を起動している
- `Info.plist`（`NSAudioCaptureUsageDescription` が必須）がリポジトリにない
- tap 対象が開始時のプロセス ID に固定されている

## スコープ外
- 他タブ音の検出、警告、分離
- macOS 25 以下への対応
- ライブ配信の録音
- 出力デバイス切り替えやスリープからの自動復旧
- 他形式への変換、文字起こし、要約などの後処理
- 複数動画の連続録音（次の動画に遷移したら停止する現行動作を維持）
- DRM の回避、録音データの配布機能。個人利用のツールとして扱う

## 用語集
- **tap**: Core Audio Process Tap。プロセスの出力音声を入力として読む仕組み
- **本編**: 広告を除いた動画の音声（rec.swift の `main` 状態）
